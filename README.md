# 박주임 강의도구 (ParkLecture)

강사가 PPT 발표나 실습 강의를 진행할 때 **전역 단축키 하나로 화면 확대, 실시간 필기·도형 판서, 칠판 전환, 마우스 커서 강조, 쉬는 시간 타이머, 판서 화면 캡처**를 사용할 수 있는 Windows 강의 도구입니다.

## 실행 방법

- `실행.cmd` 더블클릭 또는 `bin\ParkLecture.exe` 실행
- 소스 다시 빌드 및 자체 테스트:
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\build.ps1 -Test
  ```

## 전역 단축키 (설정에서 변경 가능)

| 기본 단축키 | 기능 | 설명 |
| --- | --- | --- |
| `Ctrl + 1` | **화면 확대 (Zoom)** | 마우스 이동으로 화면 탐색 · 마우스 휠로 배율 조절 · **좌클릭 시 즉시 필기 전환** · 우클릭/Esc 종료 |
| `Ctrl + 2` | **화면 필기 (Draw)** | 현재 화면을 고정하고 바로 펜·형광펜·화살표·도형·번호·글자 판서 |
| `Ctrl + 3` | **마우스 강조 토글** | PPT를 그대로 조작할 수 있는 투과형 형광 원 + 클릭 파동 효과 켜기/끄기 |
| `Ctrl + 4` | **강의 타이머** | 쉬는 시간·실습 시간 대형 카운트다운 시계 및 예상 시작 시각 표시 |

## 확대 · 판서 화면 내 단축키

- **그리기 도구**: `P` 펜, `H` 형광펜, `L` 직선, `A` 화살표, `U` 사각형, `C` 원/타원, `N` 번호 스탬프(1, 2, 3…), `T` 텍스트 입력, `Q` 레이저 포인터, `X` 부분 지우개
- **빠른 도형 그리기 (ZoomIt 호환)**: 펜 모드에서 `Shift + 드래그`(직선), `Ctrl + 드래그`(사각형), `Tab + 드래그`(원), `Ctrl + Shift + 드래그`(화살표)
- **색상 변경**: 숫자 `1~8` 또는 `R`(빨강), `G`(초록), `B`(파랑), `Y`(노랑), `O`(주황), `M`(보라)
- **굵기 및 배율 조절**: `Ctrl + 마우스 휠` 또는 `[` / `]` (펜 굵기), `마우스 휠` 또는 `+` / `-` (화면 확대 배율), `Space + 드래그` (확대 화면 이동)
- **칠판 및 조명 효과**: `W` 화이트보드, `K` 칠판(진녹색), `D` 원본 강의 화면, `S` 스포트라이트 조명(`Shift + 휠`로 조명 크기 조절)
- **편집 및 캡처**: `E` 전체 지우기, `Ctrl + Z` 실행 취소, `Ctrl + Y` 다시 실행, `Ctrl + C` 판서 화면 클립보드 복사 및 보관함 저장, `Ctrl + S` 파일 저장, `F1` 하단 안내 바(HUD) 숨기기/보이기, `우클릭` 또는 `Esc` 종료
